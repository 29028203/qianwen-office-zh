# 千问办公版本与订阅答疑：企业版积分怎么算，能增席吗，套餐能降级吗

> 原文链接：[https://www.laoshoucun.com/qianwendt/2515](https://www.laoshoucun.com/qianwendt/2515)

<p><strong>个人版和企业版差在哪？</strong></p>
<p>个人版给自己用，企业版按组织购买和管理，企业席位、统一积分池和订阅管理都算在里头。买之前把购买页的权益说明过一遍，条目都写在上面。</p>
<p><strong>企业版的积分怎么算？</strong></p>
<p>一个席位一个月 2000 积分，全进组织公用积分池，有企业版权限的成员一起花。谁花了多少，后台一笔笔都在，管理员盯总余量就行。</p>
<p><strong>当月用不完的积分，下月还能接着用吗？</strong></p>
<p>积分跟着订阅月走，当月用不完的部分，订阅月一到就清零，不结转到下月。重活排在月初跑，月底不用赶。</p>
<p><strong>积分不够烧了怎么办？</strong></p>
<p>找管理员加购就行，买积分包或者加购席位都行。积分包买完立刻进公用池，有效期从购买当天起算一年。</p>
<p><strong>扣积分按什么顺序来？</strong></p>
<p>先扣当月席位积分，再扣积分包。手里好几个积分包的，最早到期的先扣，顺序系统自己排，不用管。</p>
<p><strong>订阅期内，席位加得减不得？</strong></p>
<p>加席位随时能加，支付完就生效，费用和首期积分按剩余周期折算。减席位要等下一次续费才落地，有缩编打算的，把生效时点提前排进计划。</p>
<p><strong>一取消订阅，权益马上停？</strong></p>
<p>取消订阅关掉的是自动续费，当前已付费的周期，权益照常能用，用到周期结束为止。</p>
<p><strong>升级套餐什么时候生效？</strong></p>
<p>支付成功就生效，原套餐截止时间不变。当前周期补差价，往后按升级后的价格续费。</p>
<p><strong>套餐往低了换行吗？</strong></p>
<p>生效中的套餐想降档，先取消订阅，等当前套餐到期，再重新选低档。升级支付完就生效，降档要等到期重买。</p>
