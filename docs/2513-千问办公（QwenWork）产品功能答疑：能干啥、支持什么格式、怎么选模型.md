# 千问办公（QwenWork）产品功能答疑：能干啥、支持什么格式、怎么选模型

> 原文链接：[https://www.laoshoucun.com/qianwendt/2513](https://www.laoshoucun.com/qianwendt/2513)

<p>阿里云帮助中心的「产品与功能」FAQ，我逐条翻了一遍，按官方口径整理成下面八问八答。</p>
<p><strong>Q1：它能替你干哪些活？</strong></p>
<p>日常活基本都接：文档能写，数据能分析，资料能查，深度研究也能做。图片和音视频它能看懂，多模态内容能生成，定时任务和网页制作也没落下。部分客户端还多两块：浏览器自动化和本地文件处理。</p>
<p><strong>Q2：什么格式的文件都能吃吗？</strong></p>
<p>Word、Excel，PPT 这些文档格式都收，PDF 和 HTML 网页文件也认，图片，音视频照单全接，日常格式基本全了。某种具体格式支不支持，以产品页面的实时展示为准。</p>
<p><strong>Q3：Web 端、钉钉端，客户端，功能一样吗？</strong></p>
<p>不一样，三端的差别还不小。网页全栈制作，Web 端和钉钉端现在都有，客户端等后续开放。浏览器自动化和本地文件操作反过来，客户端独有。企业版能力目前覆盖 PC 端和 Web 端，桌面客户端还在路上。功能在哪个端，官方页面列得清楚，先查再选。</p>
<p><strong>Q4：技能指的是什么？</strong></p>
<p>为特定任务预设的专业工作流，内容创作、数据分析和信息整理这类。说白了就是把一套成熟做法打包复用，套上之后干活更顺。</p>
<p><strong>Q5：连接器是干嘛的？</strong></p>
<p>把外部平台、账号和数据接进来的那根线。部分连接器装完只是第一步，还得补配置或账号授权才能真正跑起来。</p>
<p><strong>Q6：模型该怎么选？</strong></p>
<p>输出质量、处理速度和使用成本三个变量，按任务类型取舍。复杂分析和内容创作用强模型，简单任务选响应快的就够，额度别浪费。</p>
<p><strong>Q7：能语音输入吗？</strong></p>
<p>能，开口描述需求和下达任务都行，打字这步可以省了。</p>
<p><strong>Q8：钉钉那头的内容能调出来吗？</strong></p>
<p>走完相应授权，钉钉里的文档和考勤这些能力能连上，AI 听记与知识库也能接。实际支持范围以产品页面为准。</p>
<p>八条里最容易绕弯的是 Q3 的端差异：浏览器自动化只在客户端，网页全栈制作在 Web 端和钉钉端。挑端之前，先到官方页面查清功能在哪个端。</p>
