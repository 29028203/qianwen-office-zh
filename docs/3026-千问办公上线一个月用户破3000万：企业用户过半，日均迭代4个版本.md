# 千问办公上线一个月用户破3000万：企业用户过半，日均迭代4个版本

> 原文链接：[https://www.laoshoucun.com/qianwendt/3026](https://www.laoshoucun.com/qianwendt/3026)

<p>9月4日，阿里披露了一组数据：旗下企业级通用 Agent 产品<a href="https://www.laoshoucun.com/qianwen" target="_blank" rel="noopener">千问办公</a>上线刚满一个月，用户数突破 3000 万，其中企业用户占比过半。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/09/20260904185736_492226.png" alt="千问办公用户破3000万"></p>
<p><a href="https://www.laoshoucun.com/qianwen" target="_blank" rel="noopener">千问办公</a>是8月3日上线的，30天拿到 3000 万用户，在 AI 办公赛道算头部速度。真正被阿里看重的是企业市场：一半以上用户来自企业，这也是阿里把它定义为企业级产品的底气。</p>
<p>这一个月里，<a href="https://www.laoshoucun.com/qianwen" target="_blank" rel="noopener">千问办公</a>完成了约 120 个版本的更新，平均一天迭代 4 次，累计更新上千个功能点，还推出了国际版进入全球市场。8月17日，千问办公开源了上下文基础设施 MyContext，把海量异构工作数据转成 Agent 可直接调用的上下文，开源数周就在 GitHub 拿到超过 3000 个 Star。</p>
<p>技术之外，企业里的实际用法也在铺开。发布稿里举了长安汽车的案例：线束选型计算从资深工程师手工两天缩短到五分钟，随车文件核查从单车十几分钟降到一两分钟。汇付天下在知识库、数据治理和支付场景里，把它用成了沉淀数字资产的基础设施。销售场景里，业务人员在钉钉里发一句指令，Agent 就能跨 CRM、ERP 查客户、库存和订单，直接整理出业务建议。</p>
<p>8月26日阿里发布 Qwen3.8-Flash 模型时，千问办公同步推出了专属版本，针对多步规划、工具选择、上下文压缩做了专项调优。真实办公场景的测试里，单任务生成速度提升约 100%，Token 消耗平均减少 75%。第三方数据也有参照，杰富瑞对八款全球主流 AI Agent 的实测中，千问办公综合得分排第一。</p>
<p>对正在选 AI 办公工具的企业来说，千问办公的特点是：把办公场景当主战场，同时背靠自研模型持续做专属优化。企业用户占比过半这个数据，比总用户数更能说明问题。</p>
