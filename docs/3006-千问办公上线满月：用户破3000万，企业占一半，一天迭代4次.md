# 千问办公上线满月：用户破3000万，企业占一半，一天迭代4次

> 原文链接：[https://www.laoshoucun.com/qianwendt/3006](https://www.laoshoucun.com/qianwendt/3006)

<p>9月4日，阿里披露了一组数据：旗下企业级通用Agent产品千问办公上线刚满一个月，用户数突破3000万，其中企业用户占比过半。</p>
<p>8月3日上线，30天拿下3000万用户，这个速度在<a href="https://www.laoshoucun.com/" target="_blank" rel="noopener">AI办公</a>赛道算得上头部。更值得注意的是企业市场的突破——一半以上用户来自企业，这也是阿里把它定义为企业级产品的底气所在。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/09/20260904185736_492226.png" alt="千问办公用户破3000万" style="max-width:100%;height:auto;border-radius:8px;margin:16px 0" /></p>
<h2>一个月迭代120个版本</h2>
<p>千问办公这一个月没闲着。官方口径是完成了120个版本更新，平均一天迭代4次，累计更新上千个功能点，还推出了国际版进入全球市场。这种高频节奏，背后是阿里对Agent赛道的重投入。</p>
<p>技术侧也有动作：8月17日，千问办公开源了上下文基础设施MyContext，把海量异构工作数据转成Agent可直接调用的上下文，开源数周就在GitHub拿到超过3000个Star。销售人员在钉钉里发一句指令，Agent就能跨CRM、ERP查客户、库存和订单，直接整理出业务建议。</p>
<h2>企业里的真实用法</h2>
<p>发布稿里给的案例比较能说明问题。长安汽车把千问办公用在&#8221;研产供销服&#8221;全链路：线束选型计算从资深工程师手工两天缩短到五分钟，随车文件核查从单车十几分钟降到一两分钟。汇付天下在知识库、数据治理和支付场景里把它用成了沉淀数字资产的基础设施。</p>
<p>此外，8月26日阿里发布Qwen3.8-Flash模型时，千问办公同步推出专属版：针对多步规划、工具选择、上下文压缩专项调优。真实办公场景测试里，单任务生成速度提升约100%，Token消耗平均减少75%。杰富瑞对八款全球主流AI Agent的实测中，千问办公综合得分排第一。</p>
<p>对想选AI办公工具的企业来说，这款产品的特点很明确：它是少数把&#8221;办公场景&#8221;当主战场、又背靠自研模型持续做专属优化的Agent。想看<a href="https://www.laoshoucun.com/qianwen" target="_blank" rel="noopener">千问办公</a>后续怎么打，值得盯一阵。</p>
