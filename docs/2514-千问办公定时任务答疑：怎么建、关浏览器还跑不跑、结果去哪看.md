# 千问办公定时任务答疑：怎么建、关浏览器还跑不跑、结果去哪看

> 原文链接：[https://www.laoshoucun.com/qianwendt/2514](https://www.laoshoucun.com/qianwendt/2514)

<p>把自动化办公四个字落到<a href="https://www.laoshoucun.com/qianwen" target="_blank" rel="noopener">千问办公</a>（QwenWork）里，最具体的东西就是定时任务，偏偏它也是被问得最凶的模块：怎么建、关了浏览器还跑不跑和结果去哪翻，阿里云帮助中心 FAQ 里定时任务相关的 7 个问题，我捋成下面的问答，答案全按官方口径来，直接对号入座。</p>
<p>任务怎么建。三种建法：老老实实进定时任务页面填，任务名称、计划时间和执行指令都要写上。或者直接在对话里丢一句自然语言，什么时候做什么就行。嫌麻烦的还有预置模板，改改就能用，我个人最喜欢第二种，跟聊天似的把需求说出口，任务自动立住。</p>
<p>浏览器关了，任务还跑吗。跑，任务挂在云端执行，浏览器关不关、账号退不退，已启用的任务一概不受影响，这条是被问得最多的，答案也最干脆：放心关。</p>
<p>时间上能怎么排。单次执行、固定间隔和自定义周期都行，档位从小时到月共六个，日常排程需求基本都罩得住。</p>
<p>跑完的结果去哪翻。每执行一次就生成一个独立会话，过程和结果都留在里面，想翻旧账，执行记录入口也能进。</p>
<p>点立即执行会打乱原周期吗。不会，立即执行等于额外加跑一趟，原有定时计划纹丝不动，两边互不干扰。</p>
<p>任务删了，历史还在吗。在，删任务只是让它停止运行，历史执行记录和相关会话照旧可查，误删了也不丢证据。</p>
<p>Web 端建的任务，桌面客户端能看到吗。目前看不到：Web 端和桌面客户端的定时任务，会话各管各的，暂不支持同步，眼下最该留意的限制就是这条，跨端用的人别默认这边建的另一边也找得到。</p>
<p>整套机制读下来，落点是两头：建任务的门槛压到地板，说话即建。跑任务的心智负担清零，云端执行、结果留痕。要用好它，关键就盯住最后那个坑：端独立，意味着 Web 端搭好的一套自动化，换桌面客户端得整套重来，重度用户开局就定死主用端，别两头开花，免得日后整理时两头对不齐。</p>
